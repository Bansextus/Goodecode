# Product boundary

`Goodecode source -> .goode package -> Goodebot import -> private runtime build and deployment`

Goodecode owns authoring, syntax support, official templates, structural checks, and source packaging. It does not generate runtime artifacts or certify deployability, competition safety, simulation readiness, or hardware behavior.

Goodebot owns import, robot configuration, user-facing build diagnostics, simulation, and deployment workflows. Its runtime implementation is proprietary and is not part of the public package format.
